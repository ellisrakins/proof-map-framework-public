# Contributing

Install an isolated Python 3.10+ environment with `.[test,paper,trust,dev]` plus
types-jsonschema. Run pytest, ruff check/format, scripts/check_types.py,
scripts/verify_real.py with the pinned Lean compiler, and the explicit browser
and Linux-container security suites. See docs/CI.md for actual coverage gates.

Write adversarial regressions before correcting trust defects. Preserve historical
receipts; a new replay is a new event, not an edit. No model output, unsigned receipt,
authored status, failed proof search or approximation is accepted mathematical proof.
Keep source/statement fidelity and novelty separate. Changes to parsers, policies,
digests or verifier assumptions require corpus and stale-evidence tests.

Do not regenerate tracked historical research artifacts incidentally. Fixtures
must be original or appropriately licensed and labelled. Synthetic Agoh examples
must never be presented as the original manuscript or autonomous rediscovery.
No publishing, tags, paid services or server rule changes are automatic.
